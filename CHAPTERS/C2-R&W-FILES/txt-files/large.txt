MERN STACK E-COMMERCE APPLICATION DOCUMENTATION
================================================

PROJECT NAME:
Repiit - Full Stack MERN E-Commerce Platform

--------------------------------------------------
1. PROJECT OVERVIEW
--------------------------------------------------

Repiit is a full-stack e-commerce web application built using the MERN stack:
MongoDB, Express.js, React.js, and Node.js.

The system supports:
- User Authentication
- Role-Based Authorization
- Product Management
- Cart & Wishlist System
- Order Management
- Payment Integration
- Image Upload (Cloudinary)
- Admin Dashboard
- JWT Based Security
- RESTful API Architecture

--------------------------------------------------

--------------------------------------------------
4. USER MODEL SCHEMA
--------------------------------------------------

Fields:
- name: String
- email: String
- password: String (hashed)
- role: String (user/admin)
- avatar: Object (public_id, url)
- createdAt: Date

--------------------------------------------------
5. PRODUCT MODEL SCHEMA
--------------------------------------------------

Fields:
- name: String
- description: String
- price: Number
- category: String
- stock: Number
- ratings: Number
- images: Array
- reviews: Array
- createdAt: Date

--------------------------------------------------
6. AUTHENTICATION FLOW
--------------------------------------------------

Step 1: User Registers
Step 2: Password hashed using bcrypt
Step 3: JWT token generated
Step 4: Token stored in HTTP-only cookie
Step 5: Middleware verifies token for protected routes

--------------------------------------------------
7. ROLE-BASED AUTHORIZATION
--------------------------------------------------

Roles:
- User
- Admin

Admin Capabilities:
- Add Product
- Update Product
- Delete Product
- View All Users
- Manage Orders

Middleware:
isAuthenticatedUser
authorizeRoles("admin")
